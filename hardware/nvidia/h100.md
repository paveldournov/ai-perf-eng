## Roofline Parameters

- **Ridge point (BF16):** 989e12 / 3.35e12 ≈ **295 FLOP/byte**
- **Ridge point (FP8):**  1979e12 / 3.35e12 ≈ **591 FLOP/byte**

Most LLM decode operations are memory-bandwidth-bound at these ridge points.

---

## Notable Microarchitecture Features

- **Tensor Memory Accelerator (TMA):** async bulk copy between global and shared memory; decouples data movement from compute
- **4th-gen Tensor Cores:** native FP8 (E4M3 / E5M2) with hardware scaling
- **Transformer Engine:** auto-casts between FP16 and FP8 per layer to maximize throughput
- **NVLink 4:** 18 links × 25 GB/s each = 900 GB/s bidirectional per GPU; enables NVLink Switch fabric
- **HBM3 stack:** 5 stacks × 16 GB, 3.35 TB/s aggregate

---

## SM Structure (per SM)

- 4 warp schedulers
- 4 dispatch units
- 128 FP32 CUDA cores (32 per partition)
- 4× 4th-gen tensor cores (one per partition)
- 256 KB register file
- 228 KB configurable L1/shared memory
